Standard: IEC / BS 7671 / Myanmar M&E

1. Cable Protection Rule Checker ($In \le Iz$)

MCB ၏ Ampere Rating ($In$) သည် ဝါယာကြိုး၏ ခံနိုင်ရည် ($Iz$) ထက် ငယ်ရမည် သို့မဟုတ် ညီရမည်။

2. Earth Resistance & LPS Validator

တိုင်းတာရရှိသော မြေကြီးခုခံအား (Earth Resistance) သည် စံသတ်မှတ်ချက်အတွင်း ရှိမရှိ စစ်ဆေးခြင်း။

3. RCD / ELCB Trip Time Validator

30mA RCD စမ်းသပ်စစ်ဆေးမှု စံနှုန်းများ (IEC Standards)

4. Site Engineer Core Reference Rules

🔹 MEP Clearance Rule #1: လျှပ်စစ် Cable Tray များကို ရေပိုက်များ (Plumbing/Sprinkler) ၏ အောက်တည့်တည့်တွင် လုံးဝမတပ်ဆင်ရပါ။ အထက်ဘက်မှသာ သွယ်တန်းရမည်။
🔹 Conduit Space Factor: ပိုက်အတွင်း ကြိုးထည့်ရာတွင် အပူระအာ လွတ်လပ်စွာထွက်စေရန် 45% Rule ကို တိကျစွာလိုက်နာရမည်။
🔹 DB Labeling Standard: Circuit Breaker များ၏ ညာဘက်အပေါ်ထောင့်တွင် အဝင် (Input) Label စာသားများ အပိုထပ်နေခြင်း (Duplicate labels) လုံးဝမရှိစေရ။
🔹 Fire Stopping Rule: နံရံဖောက်၍ ကြိုးဆွဲပြီးပါက မီးခိုးနှင့် မီးတောက်မကူးစက်ရန် Fire Stop Sealant ဖြင့် လေလုံအောင် ပြန်ပိတ်ရမည်။
